## ⚡ 30-Second Exam Rules for Section B (MRI Sir)
1. **Never use 365 calendar days for daily demand:** Always multiply by **260 operating days** ($5\text{ days/week} \times 52\text{ weeks}$).
2. **Always write the 4-line chain for Reorder Point ($ROP$):**
   $$
   \begin{aligned}
   \text{Reorder point } (ROP) &= \text{Average demand during lead time } (dl) + \text{Safety stock } (z\sigma_L) \\
   &= dl + z\sigma_L
   \end{aligned}
   $$
3. **Always box the Inventory Position ($IP$) decision rule:**
   $$
   \boxed{IP \le ROP} \longrightarrow \text{Place order} \quad \Big| \quad \boxed{IP > ROP} \longrightarrow \text{Do not order}
   $$
4. **Include safety stock in annual cost:**
   $$
   C = \frac{Q}{2}(H) + \frac{D}{Q}(S) + H z \sigma_L
   $$
5. **Always write the verbatim $TBO$ definition:**
   *"The average length of time that elapses between two consecutive inventory orders."*
6. **Sawtooth Graph Checklist:**
   Label axes (`Inventory Position` vs `Time`), peak height $EOQ$, horizontal dashed line $ROP$, drop lines, lead time brackets, $TBO$ arrows, and cycle break `~~~~`.
